# Revana for ChatGPT

ChatGPT plugin package for [Revana](https://revana.si): make AI videos with Seedance 2.5 from ChatGPT on your Revana account. Free quotes first, the video and a download link after you agree, and failed videos are never charged.

- MCP server: `https://revana.si/api/mcp/chatgpt` (Streamable HTTP, OAuth with dynamic client registration)
- Package: `plugin.json` (Agent Plugins format), `mcp.json`, `skills/get-started`, `assets/`
- Demo video: see the latest release
